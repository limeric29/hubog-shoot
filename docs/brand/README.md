# Hubog Shoot logo exploration

`hubog-shoot-concept-v1.png` is a transparent bitmap concept generated with the
built-in image-generation tool using the existing Hubog light lockup as the edit
reference. It explores a Shoot descriptor inside photographic viewfinder corners.

The site implements that direction with the original optimized Hubog PNG and a
separately typeset descriptor with SVG corner brackets. This preserves the exact
master mark and sharp text at small sizes; the generated bitmap is a concept,
not the production logo asset. The Hubog icon is not recolored, stretched, or
redrawn. The original brand assets are from the owner's existing `hubog.app`
product and are disclosed as prior work in the README.

The original lockup is navy on light backgrounds. Shoot uses Plus Jakarta Sans;
the viewfinder uses Electric Blue `#1677FF`. Keep at least one-third of the icon
height as clear space between the master lockup and surrounding elements. The
favicon and Apple touch icon use the existing Hubog icon.

## Generation prompt

Use case: logo-brand. Edit target: the supplied existing Hubog logo. Create one
polished horizontal Hubog Shoot sub-brand logo for a product photography studio
for small Filipino sellers. Preserve the existing gradient H icon's silhouette,
proportions, layered cyan-to-electric-blue-to-violet coloring, and orientation.
Preserve the existing lowercase navy 'hubog' wordmark and its letterforms. Add
the exact lowercase word 'shoot' to its right as a clearly separate product
descriptor, in a clean medium-weight geometric sans serif inspired by Plus
Jakarta Sans, approximately two-thirds the height of the hubog lettering. Give
'shoot' four very restrained, thin, open viewfinder corner brackets in Electric
Blue #1677FF, suggesting photographic framing without adding a separate camera
icon. Align the wordmarks optically; use intentional spacing so hubog remains
the master brand and shoot reads immediately. Color palette from the existing
brand only: cyan #00DDE5, electric blue #1677FF, violet #A855F7, Midnight Navy
#080F28; use Midnight Navy for both words. Style: precise, clean, vector-like
edges in a bitmap, professional existing-brand extension. Transparent background
with real alpha. One centered logo only, with generous clear space of at least
one-third of the H icon's height. Wide composition. Text verbatim: 'hubog shoot'.
No tagline, no .app, no extra text, no mockup, no paper, no texture, no shadows,
no ornamental gradient backgrounds, no watermark.
